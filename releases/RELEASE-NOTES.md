# Alfred 2.0.1 - Windows x64 offline Setup

Run Alfred-2.0.1-Windows-x64-Setup.exe, choose a writable folder, then launch Alfred from Start Menu. Requires Windows10 1809+/Windows11 x64 and .NET4.7.2+. Microsoft VC++ prerequisite included.

Includes CPU multilingual speech model, greeted wake, neural VAD, blue orbit visual, voice draft/correction/explicit send and normal install/uninstall with retained notes/settings. No GPU/Python/API key required. Speech accuracy and real social-site accessibility vary.

Approximately219MB. Unsigned. Tested isolated install/reinstall/uninstall and CPU transcription on the development PC; clean-PC QA remains outstanding.
