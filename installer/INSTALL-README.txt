Alfred Desktop Assistant 2.0.1

Windows 10 (1809+) or Windows 11, 64-bit; .NET Framework 4.7.2 or later; microphone access required for voice.

This standard installer includes offline English wake detection, neural VAD and a multilingual CPU speech model. No NVIDIA GPU, Python, API key, internet download or separate background server is required at runtime. The CPU model can be slower and less accurate than the CUDA Turbo development build.

Run Alfred from Start Menu. Say Hello Alfred / Hey Alfred / Okay Alfred, then a Bengali or English command. Ctrl+Alt+A listens manually; Ctrl+Alt+M pauses/resumes the microphone. Right/left click the orb or tray icon for options. Microphone pause is saved.

Open a supported chat and focus its message field; say start chat draft / চ্যাটে লেখা শুরু করো, dictate, review, correct, then explicitly say send / এবার পাঠাও. Inspect your recipient and draft. Live service accessibility varies; Bengali and mixed speech can be imperfect.

F: is preferred when present (F:\Apps\Alfred); otherwise Setup suggests the current user's LocalAppData\Programs\Alfred. You can choose another writable folder. All Alfred notes, settings and scratch live inside its installation folder. No boot autostart is enabled.

Install updates by running a newer Alfred Setup into the same folder. Settings/notes are preserved. Uninstall from Windows Installed Apps; user data is intentionally preserved.

GitHub source ZIP is not the installer. Download the *-Setup.exe from GitHub Releases once the owner publishes it. This build is unsigned; no signing certificate is configured.
